How it plugs into your panel

Panel integration

The survey ends, the panelist lands on the game with a signed link, the game server credits points back to your panel. No panel code changes beyond a redirect URL and a points endpoint.

Points are credited server-to-server. The browser never tells your panel how many points to add.

Integrity controls

RiskControl
Playing without finishing a surveysigned start link (HMAC) with a timestamp, rejected after 30 minutes
Replaying for more pointsone session per survey + panelist, idempotent credit
Editing the score in the browserserver sets wind/conditions, checks duration, input count and score limits; server decides points
Bots and scriptsminimum human play time, input timing checks, rate limits per panelist
Duplicate credits on retriesidempotency key on every points call
!
Skill, not chance. Every game here is skill-based, and every player gets points for playing. If points can be redeemed for cash or prizes, have counsel confirm the format fits the rules in the countries your panel runs in, since random-outcome prize games can fall under sweepstakes rules.
Delivery

Build plan

Open-source engine and art, production-grade integration, first game live in 2 weeks.

Engine
Phaser 3

MIT-licensed HTML5 game framework. Runs in any mobile or desktop browser, no app install.

Physics
Matter.js

MIT-licensed 2D physics for the pool table. Kicks and drives use lightweight custom ballistics.

Art
Kenney assets (CC0)

Public-domain sports sprites and UI, restyled in your panel's colors. Custom art optional.
